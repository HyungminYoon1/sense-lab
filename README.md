## 플레이

### 01. 색감 테스트

색이 다른 한 칸을 찾는 12라운드 계단식 게임입니다. 단계 4(ΔL 5%, 4×4)에서 시작해 두 번 연속 정답이면 두 단계 올라가고, 오답이면 한 단계 내려갑니다. 단계는 1–12로 제한되며 4×4 → 5×5 → 6×6, HSL 밝기 설정 차이는 14% → 0.35%입니다. 깨끗한 정답 경로는 12라운드 안에서 마지막 단계까지 도달합니다. 목표 칸은 밝거나 어두울 수 있고 색상·채도·기준 밝기·위치가 매번 바뀝니다. 정답·오답 칸을 공개하고 별도 버튼으로 다음 라운드에 진행합니다.

결과는 정답 수와 정답을 고른 가장 작은 설정 차이입니다. 응답에 따라 경로가 달라지므로 정답 수만으로 시도 간 능력을 비교하지 않습니다. ΔL은 HSL 설정 차이이며 지각 색차 ΔE, 보정된 지각 문턱이나 색각 진단 점수가 아닙니다. 작은 차이는 화면의 색 표현에서 같은 색으로 반올림될 수도 있습니다.

같은 중앙색이 배경에 따라 다르게 느껴지는 기존 색 대비 실험은 펼쳐보는 보너스로 유지했습니다.

### 02. 반응속도

시작 후 무작위 1.6–4.3초를 기다려 ‘지금!’ 신호에 반응합니다. 신호 전 클릭·터치·Space·Enter 입력은 실패합니다. 신호까지 포인터/키를 유지하거나 신호 뒤 키 반복·추가 포인터·영역 밖 입력이 있으면 제외합니다. 100 ms 미만 응답은 예측 입력, 3초 초과는 시간 초과로 제외합니다. 100 ms는 이 게임의 제외 규칙이며 사람의 생리적 능력 한계가 아닙니다. 응답 뒤 250 ms 동안 추가 입력이 없어야 기록을 확정합니다. 실패 후 계속 눌러도 새 시도나 점수가 생기지 않으며 별도 다음 시도 버튼을 사용해야 합니다. 마우스·터치의 Pointer Events, 키보드, 보조 기술의 버튼 click 경로를 처리합니다.

정상 기록 5회의 중앙값·중앙 절대 편차(MAD)·범위·조기 입력 및 기타 제외 횟수를 표시합니다. 중앙값과 MAD는 한 번의 큰 지연에 덜 흔들리지만, 유효 범위 안의 느린 기록을 임의로 버리지는 않습니다. 최대 15회 시도에서 세션을 끝내며 5회 미달은 참고 기록만 표시합니다. 실패·화면 이동·숨김·포커스 이탈·입력 확인 중 취소는 정상 기록에 넣지 않습니다. 단조 증가 브라우저 시간과 같은 시간 기준의 이벤트 시각을 사용하며 실제 화면과 입력 기기의 지연을 포함합니다. 클라이언트 입력 처리이지 보안 수준의 부정행위 방지나 공인 검사 도구는 아닙니다.

### 03. 고주파 챌린지

10,000–18,000 Hz를 1,000 Hz 간격으로 제공합니다. A/B 중 한 구간에는 짧은 사인파를, 다른 구간에는 침묵을 재생합니다. 방문자는 A·B·둘 다 안 들림 중 하나를 선택하고 주파수와 소리가 있던 구간을 확인합니다. 최종 결과는 구간 선택의 일치 수와 주파수별 응답 기록입니다. 우연히 정답을 고를 수 있으므로 청력 나이·의학적 청력·정밀 가청 한계로 환산하지 않습니다.

소리는 버튼을 눌러야 시작하고 음량을 자동으로 높이지 않습니다. 즉시 중단·탭 이동·페이지 숨김·종료 시 재생을 취소합니다. 고주파 챌린지의 최대 gain은 0.02이지만 실제 청취 음압을 보장하지는 않으므로 **기기 음량을 낮추고 안 들려도 음량을 올리지 마세요.** 기기의 고주파 재생 특성과 환경이 결과에 영향을 줍니다. 사인파·삼각파·사각파 비교(80–2,000 Hz)는 보너스로 별도 유지합니다.

### 04. 패턴 스튜디오

기존 입자 실험을 유지했습니다. 포인터·터치·방향키, 끌어당김/밀어냄, 점의 개수·잔상, 일시정지·초기화·PNG 다운로드를 지원합니다. 과학적 물리 모델이 아닌 그래픽 패턴입니다.

### 05. 위치 순서 기억

4×4 격자에서 3–7개 위치를 보여준 뒤 같은 순서로 선택하는 8라운드입니다. 위치는 순서 안에서 중복되지 않으며 매번 섞입니다. 칸 번호와 강조 표시, 상태 안내를 함께 제공합니다. 시작 전 보통(0.85초)·천천히(1.5초)를 선택할 수 있고 응답에는 시간 제한이 없습니다. 보기 중 입력을 막고 완료/오답 뒤 정답 순서를 공개합니다. 중단·화면 이동·숨김·포커스 이탈은 현재 순서를 취소하며 해당 라운드에 새 순서를 뽑아 다시 도전합니다. 결과는 순서 일치 횟수와 가장 긴 일치 순서입니다. 표시 속도·전략에 영향을 받는 게임이며 기억력 진단 점수가 아닙니다.

색·반응·기억 도전은 새 시도/초기화마다 페이지 메모리의 난수 시드를 생성합니다. 순수 모델은 난수 함수를 주입할 수 있어 고정 시드로 재현 테스트가 가능합니다. 시드는 저장·전송하지 않습니다. 결과는 아래의 기기 내 기록으로만 남습니다.

## 개인 기록

색감·반응·순서 기억의 최근 20회씩을 이 브라우저에 저장합니다. 각 기록을 펼치면 라운드별 결과를 볼 수 있습니다. 새 테스트는 현재 플레이를 다시 시작하며 저장 기록은 보존합니다. `이 기록 삭제`는 한 번의 기록만, `전체 기록 삭제`는 이 서비스의 기록과 갤러리 완료 요약만 삭제합니다.

- 색감: 12답안 뒤 `결과 보기`를 누르면 정답 여부·단계·ΔL을 저장합니다. 최근 정답 수와 이전 대비 차이를 표시하지만 경로가 달라 능력 변화로 해석하지 않습니다.
- 반응: 정상 5회 또는 최대 15시도 종료 시, 확정된 ms와 조기 입력·기타 제외·중단 상태를 저장합니다. 중앙값·MAD·범위와 모든 시도를 볼 수 있습니다. 최근 비교와 완료 배지는 정상 5회를 모은 기록만 사용합니다.
- 순서 기억: 8라운드 후 정답 여부·순서 길이·보기 속도를 저장합니다. 최근 정답 수와 이전 대비 차이는 같은 속도끼리 비교합니다. 순서 자체는 저장하지 않습니다.

청취·패턴, 중도 종료한 테스트, 시드·정답 위치·키 입력·설정은 저장하지 않습니다. 오래된 기록은 같은 테스트의 21번째 저장 시 먼저 들어온 순서대로 삭제하며 시간 기준 자동 만료는 없습니다. 손상·알 수 없는 버전의 기록은 덮어쓰지 않고 전체 삭제로 복구합니다. 저장 공간 차단·부족·삭제 실패 시 안내를 표시하며 게임은 계속 사용할 수 있습니다. 동시 탭 쓰기는 원자적이지 않아 경합할 수 있습니다.

## 실행·검증·배포

Node.js 22 이상, 패키지 설치 없이 실행합니다.

```sh
git clone https://github.com/HyungminYoon1/sense-lab.git
cd sense-lab
npm run dev -- 0
npm test
npm run check
```

출력된 Local 주소를 엽니다. 0은 임시 포트를 자동 선택하며, 소스 수정 후 새로고침합니다. 같은 기록을 확인하려면 같은 출처·포트를 유지하세요. 29개 테스트는 색·반응·기억 계산, 저장 형식·정상/불가능 종료·손상/버전/용량/삭제 실패, 완료 요약의 경계와 다른 앱 보존, 기존 모델, 실제 앱 이벤트를 연결한 DOM/시계/저장 테스트 더블, 정적 접근성 연결 및 오디오 취소의 테스트 더블을 포함합니다. 테스트 더블은 실제 브라우저·스크린리더·청취 품질 증거가 아닙니다. [검증 기록](docs/verification.md)에서 LOCAL·TEST_DOUBLE·REMOTE_CI·LIVE·NOT_RUN을 구분합니다.

Pages Source는 GitHub Actions입니다. main에 푸시하면 테스트·정적 검사를 통과한 뒤 dist만 배포합니다. 상대 경로 자산으로 프로젝트 Pages URL을 지원합니다.

## 데이터와 제작

`sense-lab-history-v1`은 version 1과 테스트별 기록 배열을 담습니다(최대 60기록, 65,536문자). 무작위 기록 ID와 실제 완료 ISO 시각 외에는 위의 라운드 결과만 저장합니다. 설정·현재 플레이·오디오·입자 패턴은 메모리에만 존재합니다. PNG는 사용자의 기기에만 다운로드됩니다. 전역 순위·계정·업로드·마이크·분석 도구·외부 API는 없습니다. GitHub의 호스팅 자체 로그는 별개입니다. 외부 글꼴과 추적 스크립트를 불러오지 않습니다.

갤러리는 `web-lab-progress-v1`의 최소 요약만 읽습니다. sense-lab의 `completed`는 저장된 독립 완료 테스트 종류 수(0–3), `total`은 3, `updatedAt`은 남아 있는 완료 기록 중 최신 실제 시각입니다. 색감 12라운드, 정상 반응 5회, 순서 기억 8라운드를 각각 한 종류로 셉니다. 점수·방문 횟수·시드·이름·입력 기록은 요약에 담지 않습니다. 초기 화면·보너스·중도 종료는 배지를 만들지 않습니다. 기록 삭제 후 남은 완료 종류 수를 다시 계산하고, 전체 삭제에서는 sense-lab 항목만 지웁니다. 다른 14개 허용 서비스의 요약은 보존합니다.

같은 출처의 다른 Pages 앱은 브라우저 저장 공간에 접근할 수 있습니다. 갤러리의 최소 요약 읽기는 통합 계약이며 브라우저의 접근 격리는 아닙니다. 공용 기기에서는 사용 후 기록을 삭제하세요. 저장 기록은 서버에 전송하지 않습니다. 다른 브라우저·기기·출처·포트와 동기화하지 않습니다.
