# SENSE LAB — 감각 아케이드

설명만 읽는 실험실 대신, 직접 플레이하고 결과를 비교하는 브라우저 감각 게임입니다.

- [사이트](https://hyungminyoon1.github.io/sense-lab/)
- [저장소](https://github.com/HyungminYoon1/sense-lab)

## 플레이

### 01. 색감 테스트

색이 다른 한 칸을 찾는 12라운드입니다. 4×4에서 5×5로 격자가 커지고 HSL 밝기 차이가 14%에서 0.6%까지 줄어듭니다. 정답·오답 칸을 공개하고, 다음 라운드는 별도 버튼으로 진행합니다. 결과는 정답 수와 이번에 구분한 최소 밝기 차이입니다. ΔL은 이 게임의 HSL 밝기 설정 차이이며 지각 색차 ΔE나 색각 진단 점수가 아닙니다.

같은 중앙색이 배경에 따라 다르게 느껴지는 기존 색 대비 실험은 펼쳐보는 보너스로 유지했습니다.

### 02. 반응속도

시작 후 무작위 1.6–4.3초를 기다려 ‘지금!’ 신호에 반응합니다. 신호 전 클릭·터치·키 입력은 실패하며, 키 반복 입력도 대기 중이면 실패합니다. 실패 후 테스트 영역을 계속 눌러도 새 시도를 시작하지 않습니다. 별도 재시도 버튼을 사용해야 합니다.

정상 기록 5회의 중앙값·최고 기록·조기 클릭 횟수를 표시합니다. 실패·화면 이동·숨김·포커스 이탈로 중단된 시도는 정상 기록에 넣지 않습니다. 브라우저의 단조 증가 시간을 사용하며 실제 화면과 입력 기기의 지연을 포함합니다. 클라이언트 입력 처리이지 보안 수준의 부정행위 방지나 공인 검사 도구는 아닙니다.

### 03. 고주파 챌린지

10,000–18,000 Hz를 1,000 Hz 간격으로 제공합니다. A/B 중 한 구간에는 짧은 사인파를, 다른 구간에는 침묵을 재생합니다. 방문자는 A·B·둘 다 안 들림 중 하나를 선택하고 주파수와 소리가 있던 구간을 확인합니다. 최종 결과는 구간 선택의 일치 수와 주파수별 응답 기록입니다. 우연히 정답을 고를 수 있으므로 청력 나이·의학적 청력·정밀 가청 한계로 환산하지 않습니다.

소리는 버튼을 눌러야 시작하고 음량을 자동으로 높이지 않습니다. 즉시 중단·탭 이동·페이지 숨김·종료 시 재생을 취소합니다. 고주파 챌린지의 최대 gain은 0.02이지만 실제 청취 음압을 보장하지는 않으므로 **기기 음량을 낮추고 안 들려도 음량을 올리지 마세요.** 기기의 고주파 재생 특성과 환경이 결과에 영향을 줍니다. 사인파·삼각파·사각파 비교(80–2,000 Hz)는 보너스로 별도 유지합니다.

### 04. 패턴 스튜디오

기존 입자 실험을 유지했습니다. 포인터·터치·방향키, 끌어당김/밀어냄, 점의 개수·잔상, 일시정지·초기화·PNG 다운로드를 지원합니다. 과학적 물리 모델이 아닌 그래픽 패턴입니다.

## 실행·검증·배포

Node.js 22 이상, 패키지 설치 없이 실행합니다.

```sh
git clone https://github.com/HyungminYoon1/sense-lab.git
cd sense-lab
npm run dev -- 0
npm test
npm run check
```

출력된 Local 주소를 엽니다. 0은 임시 포트를 자동 선택하며, 소스 수정 후 새로고침합니다. 14개 테스트는 색·반응 계산과 기존 모델, 오디오 취소의 테스트 더블을 포함합니다. 실제 청취 품질이나 모든 기기에서의 실행을 보장하는 테스트는 아닙니다. [검증 기록](docs/verification.md)에서 LOCAL·TEST_DOUBLE·REMOTE_CI·LIVE·NOT_RUN을 구분합니다.

Pages Source는 GitHub Actions입니다. main에 푸시하면 테스트·정적 검사를 통과한 뒤 dist만 배포합니다. 상대 경로 자산으로 프로젝트 Pages URL을 지원합니다.
