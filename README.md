# SENSE LAB — 감각 아케이드

색·반응·고주파 청취·음높이·위치 기억·시각 시간 순서를 다루는 여섯 가지 브라우저 과제입니다.

[실행](https://hyungminyoon1.github.io/sense-lab/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/) · [구조](architecture.md) · [변경 결정](docs/decisions.md) · [검증 기록](docs/verification.md)

## 테스트

| 과제 | 기본 | 더 어려운 도전 | 결과 |
| --- | --- | --- | --- |
| 색감 | 12라운드, ΔL 5%부터 | ΔL 1.2%부터, 최소 0.35%, 최대 6×6 | 정답 수·정답 중 최소 밝기 차이 |
| 반응속도 | 초록색 ‘지금!’에 한 번 입력, 정상 5회 | 방해 문구 ‘아직!’ 무시, 무작위 1.6–6.5초 대기 | 중앙값·MAD·범위·실패 횟수 |
| 고주파 청취 | 10–18 kHz 9종을 무작위 순서로 A/B 구분 | 각 주파수 두 번씩 섞은 18문제 | 구간 일치 수·두 번 모두 일치한 주파수 수 |
| 음높이 | 두 음의 높낮이, 75센트부터 12문제 | 15센트부터, 최소 3센트 | 정답 수·정답 중 최소 센트 차이 |
| 위치 순서 기억 | 연습 4×4, 3–7칸 | 기본 선택 5×5·4–11칸, 역순 6×6·6–13칸 | 전체 순서 일치 수·최장 정답 길이 |
| 시각 시간 순서 | 먼저 밝아진 점 선택, 7프레임부터 12문제 | 3프레임부터, 최소 1프레임 | 정답 수·표시 간격별 정답 수·ms |

색·음높이는 두 번 연속 정답이면 두 단계 어려워지고 오답이면 한 단계 쉬워집니다. 시간 순서는 두 번 연속 정답이면 한 단계 어려워집니다. 위치 기억은 매번 다른 위치를 번호 없이 보여주며, 답을 마친 뒤 정답 순서 번호를 공개합니다. 공간 도전은 칸마다 650ms, 역순은 450ms이며 사이에 350ms 간격을 둡니다. 연습은 850/1500ms를 선택합니다. 응답 시간 제한은 없습니다. 역순은 마지막 위치부터 거꾸로 답합니다.

반응속도는 신호 전 입력·누른 채 유지·연타·100ms 미만·3초 초과를 제외합니다. 반응 뒤 250ms 동안 추가 입력이 없어야 확정합니다. 정상 5회 또는 최대 15시도에서 끝나며, 5회 미달은 완료로 세지 않습니다. 100ms는 게임의 제외 규칙이지 생리적 능력 한계가 아닙니다. 기본과 집중 모드는 서로 다른 조건입니다.

시간 순서는 빠르게 클릭하는 검사가 아닙니다. 두 점의 **등장 순서**를 본 뒤 천천히 답해도 됩니다. 두 점을 동시에 지워 사라지는 순서가 힌트가 되지 않게 했습니다. 30프레임의 화면 갱신 간격을 확인하고 불안정한 표시를 채점에서 제외합니다. 작은 중성색 점을 각 한 번 표시하며, 시작 간격은 취소·재시작에도 최소 2초입니다. 반복 점멸·붉은색 자극·전체 화면 자극은 없습니다.

## 결과와 저장

- 결과와 현재 문제는 기본적으로 메모리에만 있습니다. ‘이 결과 저장’을 눌러야 상세 기록을 남깁니다. 새 테스트·새로고침으로 저장하지 않은 결과는 사라집니다.
- 상세 기록과 별개로, 실제 테스트를 끝내면 해당 종류의 완료 여부만 자동으로 남깁니다. WEB LAB은 **n/6종 체험 완료**만 읽고 점수나 개인 결과를 읽지 않습니다. 정답률이나 능력 등급이 아닙니다.
- 기존 `sense-lab-history-v1` 기록은 자동 변환·삭제·덮어쓰기 없이 표시합니다. 이전 번호 표시 기억 과제는 새 과제와 구분합니다.
- 새 상세 기록은 `sense-lab-records-v2`에 종류별 최근 20회, 최대 131072문자로 저장합니다. 기존 기록은 별도로 보존됩니다. 시간에 따른 자동 만료는 없습니다.
- `sense-lab-completion-v1`은 6개 종류별 완료 시각만 갖습니다(최대 1024문자). `web-lab-progress-v1`에는 완료 수/전체 6/최근 실제 완료 시각만 반영합니다.
- 상세 기록 삭제와 체험 완료 표시 초기화는 별개입니다. 기존 기록에서 완료 여부를 가져온 뒤 초기화해도 옛 기록 때문에 배지가 다시 생기지 않습니다. 다른 앱 기록은 수정하지 않습니다.
- 저장 차단·용량 부족·읽기 확인 실패·손상된 데이터는 안내하고 원본을 보존합니다. 상세 저장과 완료 요약 중 한쪽만 실패할 수 있습니다. 동시 탭 쓰기는 원자적이지 않아 경합할 수 있습니다.

이 브라우저에서만 보관하며 계정·서버 동기화·공개 랭킹은 없습니다. 같은 출처의 다른 GitHub Pages 앱은 저장 공간에 접근할 수 있으므로 경로가 개인정보 격리 경계는 아닙니다. 공용 기기에서는 상세 기록과 완료 표시를 각각 삭제하세요.

## 안전과 해석

소리는 버튼으로만 재생하며, 음량을 자동으로 높이지 않습니다. 기기 음량을 낮추고 **안 들려도 올리지 마세요**. 불편하면 즉시 중단하세요. A/B와 음높이 소리의 앱 gain 상한은 0.02이며 실제 청취 음압을 보증하지 않습니다. 빛 자극에 민감하거나 광과민성 발작 경험이 있으면 시간 순서 과제에 참여하지 마세요. 중단·Escape(시간 순서)·화면 이동·페이지 숨김은 진행 중인 자극을 취소합니다.

이 결과는 게임 조건에서 관찰한 응답입니다. 청력 나이·색각 진단·임계깜박이 주파수·사람 간 백분위를 계산하지 않습니다. 화면과 입력 기기의 지연, 소리 재생 특성, 우연한 정답이 영향을 줍니다. 한 번의 최소 정답을 안정적인 감각 한계로 해석하지 마세요.

## 실행·검증·배포

Node.js 22 이상, 런타임 패키지 설치 없이 실행합니다.

```sh
npm run dev -- 0
npm test
npm run check
```

출력된 loopback 주소에서 확인합니다. 도구·테스트는 배포하지 않고 `dist`만 기존 GitHub Actions로 배포합니다. 브라우저 검증은 `tools/browser-20261019.mjs`를 별도로 실행하며 기존 작업용 Playwright 설치가 필요합니다. 자동 테스트의 소리는 음소거되며, 실제 사람의 청취 능력·물리 화면 타이밍을 검증한 것은 아닙니다. 로컬·테스트 더블·원격 CI·공개 확인은 [최신 검증 기록](docs/sense-upgrade-20261019.md)에 구분합니다.

브라우저 전용 정적 HTML/CSS/ES modules. 마이크·계정·업로드·외부 API·분석·외부 글꼴·추적 스크립트는 없습니다. GitHub의 호스팅 로그는 별개입니다. UTF-8 without BOM / CRLF. 라이선스는 별도로 부여하지 않았습니다.
